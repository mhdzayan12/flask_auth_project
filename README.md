# Flask Authentication System 🔐

A secure authentication system built using Flask.

## 🚀 Features
- User Registration
- Login System
- Password Hashing
- Flash Messages
- Clean UI Design

## 🛠️ Technologies Used
- Python
- Flask
- HTML
- CSS
- SQLite
- Git
